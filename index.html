About

I design, build and operate secure, scalable applications — mostly on the JVM. My core strengths are Java and Spring Boot, microservice and REST API design, and cloud-native delivery on AWS, with full-stack work in React and TypeScript when the product needs it.

Today I build healthcare information systems. Before that, a large part of my work was identity and access management: OAuth2 and OIDC flows, SAML federation, SCIM provisioning and large-scale identity migrations for enterprise customers. Earlier, I built and modernised multi-tenant SaaS ERP modules for the education sector. I enjoy mentoring engineers, raising secure-coding standards and turning legacy systems into maintainable ones.

Selected work

Problem, stack, outcome. Described by domain — not by customer.

Enterprise identity federation & SSO

Enterprise customers in sports media and banking needed a single identity layer across many applications and identity providers.

Stack Okta, Auth0, Spring Boot, OIDC, SAML, OAuth2

Outcome Federated SSO with standards-based authentication across tenants, replacing bespoke per-app login.

SCIM connectors & bulk identity migration

Thousands of identities had to move from a self-hosted identity provider to a cloud IdP without data loss or onboarding delays.

Stack Java, SCIM 2.0, Keycloak → Okta, REST

Outcome Custom SCIM connectors and a bulk migration tool cut onboarding time and kept the migration secure and auditable.

Legacy IAM connector modernisation

Ageing identity connectors were slow to change and had no automated security scanning.

Stack Java, Spring Boot, Checkmarx, CI/CD

Outcome Faster, more maintainable connectors with static analysis enforcing secure coding in the pipeline.

Multi-tenant education ERP (SaaS)

Institutions needed HR & payroll, CRM, CMS and online examination on one tenant-isolated platform.

Stack Spring Boot, React, PostgreSQL, Thymeleaf, Docker on AWS EC2

Outcome Re-architected CRM, 25%+ performance gains, monolith split into modules, and smoother institutional onboarding through stronger multi-tenancy.

Pre-sales service estimation tool

Engineering estimates for enterprise deployments were inconsistent and slow to produce.

Stack Java, Spring Boot, React

Outcome More accurate estimates and shorter enterprise deployment cycles.

E-commerce web application

A full-stack storefront with secure accounts, catalogue, cart and payments.

Stack Spring Boot, JSP, MySQL

Outcome End-to-end purchase flow with authenticated users and integrated payment.

Inventory management system

Stock levels drifted and shortages were noticed too late.

Stack Java, MySQL, role-based access control

Outcome Real-time stock tracking, automated alerts and reporting with per-role access.

Secured REST API platform

Application data needed a documented, access-controlled API surface.

Stack Spring Boot, JPA, JWT, Swagger / OpenAPI

Outcome Documented, token-secured APIs ready for frontend and partner consumption.
